### ضمیمه الف-1: نمودار مصرف CPU در معماری Monolithic Node.js

**توضیح**: این نمودار نشان می‌دهد که در معماری Monolithic Node.js، تنها Core 1 با 90-100% استفاده می‌شود و سایر هسته‌ها (Core 2-16) زیر 5% استفاده دارند.

**نکات کلیدی**:

- بوتلنک Event Loop در Core 1
- هدررفت 95% ظرفیت CPU
- عدم استفاده از Multi-Core Architecture

**توضیح**: این نمودار الگوی Sawtooth (دندانه‌ای) مصرف حافظه را نشان می‌دهد که ناشی از Garbage Collection در Node.js است.

**نکات کلیدی**:

- نوسان شدید بین 60-90%
- الگوی Garbage Collection
- مدیریت حافظه ناکارآمد

### ضمیمه الف-3: نمودار مصرف CPU در معماری Multi-Core Go

**توضیح**: این نمودار نشان می‌دهد که در معماری Go، همه 16 هسته به صورت متعادل استفاده می‌شوند.

**نکات کلیدی**:

- توزیع متعادل بار کاری
- استفاده از همه هسته‌ها
- بهبود 400% در استفاده از CPU

### ضمیمه الف-4: نمودار مصرف RAM در معماری Multi-Core Go

**توضیح**: این نمودار نشان می‌دهد که مصرف حافظه در Go پایدار و قابل پیش‌بینی است.

**نکات کلیدی**:

- کاهش 70% مصرف RAM
- حذف نوسانات شدید
- پایداری بیشتر سیستم

### ضمیمه الف-5: مقایسه عملکرد Node.js vs Go

**توضیح**: این نمودار مقایسه مصرف منابع بین Node.js و Go را نشان می‌دهد.

**نکات کلیدی**:

- Node.js: مصرف منابع بالا، نوسان زیاد
- Go: مصرف منابع متعادل، پایداری بیشتر

### ضمیمه ج-2: پیاده‌سازی Sharding

```javascript
class ShardManager {
  constructor(shardCount) {
    this.shardCount = shardCount;
    this.shards = [];

    for (let i = 0; i < shardCount; i++) {
      this.shards.push(new Shard(i));
    }
  }

  getShard(key) {
    const hash = this.hash(key);
    const shardIndex = hash % this.shardCount;
    return this.shards[shardIndex];
  }

  hash(key) {
    let hash = 0;
    for (let i = 0; i < key.length; i++) {
      const char = key.charCodeAt(i);
      hash = (hash << 5) - hash + char;
      hash = hash & hash; // Convert to 32bit integer
    }
    return Math.abs(hash);
  }
}
```

### ضمیمه ج-3: پیاده‌سازی Atomic Design

```javascript
class AtomicFilter {
  constructor(config) {
    this.config = config;
    this.filters = [];
  }

  addFilter(filter) {
    this.filters.push(filter);
  }

  process(data) {
    // Process without external dependencies
    return this.filters.every((filter) => filter(data));
  }

  // No external state dependencies
  isAtomic() {
    return true;
  }
}

class PriceFilter extends AtomicFilter {
  constructor(minPrice, maxPrice) {
    super({ minPrice, maxPrice });
  }

  process(data) {
    return (
      data.price >= this.config.minPrice && data.price <= this.config.maxPrice
    );
  }
}
```

### ضمیمه ج-4: پیاده‌سازی Go Goroutines

```go
package main

import (
    "fmt"
    "sync"
    "time"
)

type ArbitrageProcessor struct {
    exchanges []Exchange
    results   chan ArbitrageResult
}

func (ap *ArbitrageProcessor) ProcessArbitrage() {
    var wg sync.WaitGroup
    results := make(chan ArbitrageResult, len(ap.exchanges))

    for _, exchange := range ap.exchanges {
        wg.Add(1)
        go func(ex Exchange) {
            defer wg.Done()
            result := ap.processExchange(ex)
            results <- result
        }(exchange)
    }

    go func() {
        wg.Wait()
        close(results)
    }()

    for result := range results {
        ap.processResult(result)
    }
}

func (ap *ArbitrageProcessor) processExchange(exchange Exchange) ArbitrageResult {
    // Process exchange data
    return ArbitrageResult{
        Exchange: exchange.Name,
        Price:    exchange.Price,
        Time:     time.Now(),
    }
}
```

### ضمیمه ج-5: پیاده‌سازی Sharding در Go

```go
package main

import (
    "hash/fnv"
    "sync"
)

type ShardManager struct {
    shards     []Shard
    shardCount int
    mutex      sync.RWMutex
}

func NewShardManager(shardCount int) *ShardManager {
    shards := make([]Shard, shardCount)
    for i := 0; i < shardCount; i++ {
        shards[i] = NewShard(i)
    }

    return &ShardManager{
        shards:     shards,
        shardCount: shardCount,
    }
}

func (sm *ShardManager) GetShard(key string) Shard {
    sm.mutex.RLock()
    defer sm.mutex.RUnlock()

    hash := fnv.New32a()
    hash.Write([]byte(key))
    shardIndex := hash.Sum32() % uint32(sm.shardCount)

    return sm.shards[shardIndex]
}

func (sm *ShardManager) ProcessData(key string, data interface{}) {
    shard := sm.GetShard(key)
    shard.Process(data)
}
```
